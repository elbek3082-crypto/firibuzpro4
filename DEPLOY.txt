FiribStop UZ 2.3.6 — Russian news feed + CARTO map

Render:
- Runtime: Node
- Build command: npm install
- Start command: npm start
- Health check: /api/health

После обновления:
1. Загрузите содержимое проекта в репозиторий GitHub.
2. Дождитесь успешного деплоя Render.
3. Откройте сайт и нажмите Ctrl+Shift+R.
4. Откройте раздел «Новости кибербезопасности» — материалы должны появляться карточками внутри интерфейса.
5. Откройте «Карта киберугроз Узбекистана» — карта использует CARTO, при ошибке тайлов переключается на OpenStreetMap.

Публикации RSS кэшируются сервером на 10 минут. Для работы ленты и фоновой карты нужен интернет. Если конкретная RSS-лента недоступна, остальные источники продолжают работать.
