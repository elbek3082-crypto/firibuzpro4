FiribStop UZ — Offline Shield 2.3.6

Изменения 2.3.6:
- Региональная карта использует тёмную подложку CARTO; OpenStreetMap остаётся резервным вариантом.
- Раздел Cyber Trends заменён на собственную интерактивную региональную карту, не зависящую от встраивания сторонней страницы.
- Лента новостей ориентирована на русскоязычные RSS-источники: UZCERT, SecurityLab, Securelist, Positive Technologies и BI.ZONE.
- Заголовки, даты, категории и краткие описания новостей отображаются непосредственно в интерфейсе FiribStop; переход к оригиналу оставлен как дополнительная ссылка для проверки.
- Обновлён кеш Service Worker для загрузки новой версии интерфейса.

Важно: карта показывает административные границы и текстовые упоминания в публикациях. Она не является подтверждённой статистикой атак в реальном времени. Число публикаций не равно числу инцидентов.

Запуск:
1. Требуется Node.js 18 или новее.
2. Выполните npm install (дополнительные пакеты для базового сервера не нужны).
3. Выполните npm start.
4. Откройте http://localhost:3000.

Развёртывание на Render: используйте настройки из render.yaml. После публикации очистите кеш браузера или выполните Ctrl+Shift+R.


Версия 2.3.8: карта использует OpenStreetMap без CARTO API key и получает неоновое киберпанк-оформление. Новостная лента в интерфейсе сохранена.
